# Icons

This directory should contain the extension icons.

For now, you can use any 48x48 and 96x96 PNG images as placeholders.

## Required files:
- `icon-48.png` - 48x48 pixels
- `icon-96.png` - 96x96 pixels

You can create simple icons using any image editor or online icon generators.

For a quick placeholder, you can:
1. Use a screenshot tool to create a 48x48 and 96x96 colored square
2. Use an online favicon generator
3. Use any bookmark/folder icon you find online

The extension will still work without icons, but Firefox will show a default icon instead.
