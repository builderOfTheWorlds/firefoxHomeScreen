Settings

GitHub Configuration

Configure your GitHub repository to sync your bookmarks across devices.

Create a token with 'repo' scope
Format: owner/repository (e.g., "builderOfTheWorlds/firefoxHomeScreen")
Path to the bookmarks configuration file in your repository

Instructions

  1. Create a GitHub repository (public or private) to store your bookmarks configuration
  2. Create a Personal Access Token with 'repo' scope at GitHub Settings
  3. Create a bookmarks.json file in your repository with your bookmarks structure
  4. Enter your settings above and click Save
Example bookmarks.json structure
