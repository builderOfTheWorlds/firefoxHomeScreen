Import VS Code Theme

Import any VS Code theme .json file. Find themes on GitHub — look in the themes/ folder of any VS Code theme repo. Imported themes appear in the Background Theme picker above.

Instructions

  1. Create a GitHub repository (public or private) to store your bookmarks configuration
  2. Create a Personal Access Token with 'repo' scope at GitHub Settings
  3. Create a bookmarks.json file in your repository with your bookmarks structure
  4. Enter your settings above and click Save
